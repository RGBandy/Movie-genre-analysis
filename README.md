# Movie-genre-analysis
Analyzing movie ratings and genres using Python, SQL, and IMDb datasets from 2026

All that needs to be adjusted is the header variable within the Jupyter file. This is because you need a unique API to access the database which is obtained upon request. Click the url within this file to head to the database.

This final excel file is the finished version of the cleaned data with removed duplicates, null data, along with visualizations to make better analysis.
